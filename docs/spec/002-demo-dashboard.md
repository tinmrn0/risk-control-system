# 002 - 演示控制台（Demo Dashboard）

## 背景与目的

现场演示需要可视化界面替代 curl：直观展示风险决策、规则配置、命中记录，并能一键复现并发压测。

## 范围

单文件 `src/main/resources/static/index.html`，由 Spring Boot 静态资源直接服务（同源无 CORS），零构建链、零外部依赖。

### 区块

1. **风险检查**：表单 + 预置场景按钮（正常 / 大额 / 黑名单 / 时段外），展示决策徽章、命中规则明细、耗时
2. **并发压测**：一键发起 30 请求 / 10 并发 / 同一用户，统计 PASS / REVIEW 分布，复现 README 验证记录
3. **规则列表**：只读展示规则配置
4. **命中记录**：分页查询 + 手动刷新

## 非目标

- 不引入前端框架与构建工具
- 不做登录体系；沿用 X-Api-Key 鉴权，Key 由页面输入框提供（localStorage 记忆，不硬编码）
- 仅本地/内网演示用途

## 验收标准

- [ ] 应用启动后访问 `http://localhost:8080/` 可用
- [ ] 四个区块均能正确渲染接口数据
- [ ] 预置场景一键触发且决策结果与 README 验证记录一致
- [ ] 压测按钮可复现"30 并发下 PASS/REVIEW 精确切分"结果
- [ ] 无外部 CDN / 字体 / 图片依赖，单文件可离线打开
