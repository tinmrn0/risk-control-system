# 安全规则（rule：常驻约束，每次会话生效）

本系统面向资金安全场景，以下规则优先级高于编码规范中的其他约定：

- 所有外部入参必须校验：类型、范围、非空、长度，禁止信任客户端任何数据
- SQL 一律预编译（MyBatis `#{}`），禁止 `${}` 拼接；动态排序 / 字段名必须走白名单映射
- 敏感字段（手机号、证件号、卡号）日志输出必须脱敏；日志与异常信息禁止出现密钥、完整卡号
- 接口必须有鉴权校验；数据查询必须带数据归属条件，防止水平越权
- 频率类计数一律 Redis + Lua 原子执行（ZADD + ZREMRANGEBYSCORE + ZCARD 同一脚本），禁止先读后写
- 密钥、连接串密码禁止硬编码，统一环境变量注入
